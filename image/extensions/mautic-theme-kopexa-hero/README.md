# Kopexa · Hero + Split

Variant of the [Kopexa email theme](../mautic-theme-kopexa): Hero on the dark surface, two cards with images (stack on mobile), one full-width feature with a large image. Delete the parts you don't need; images are placeholders.

![Preview](thumbnail.png)

Head, header and footer are identical to the base theme and its assets
(fonts, logo, images) are used; the quality gate and the builder rules are
described there.
