# Kopexa · Anmeldung bestätigen

Variant of the [Kopexa email theme](../mautic-theme-kopexa): Double opt-in confirmation email: one task, one button to `{doi_link}` (Leuchtfeuer DOI plugin, built into the image).

![Preview](thumbnail.png)

Head, header and footer are identical to the base theme and its assets
(fonts, logo, images) are used; the quality gate and the builder rules are
described there.
